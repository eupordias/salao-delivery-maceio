## 🌟 Sobre o Projeto

O **Salão Delivery Maceió** é um ecossistema digital desenvolvido para **revolucionar o mercado de beleza alagoano**, levando serviços de alto padrão — como aplicação de Mega Hair, Selagem, Progressiva e coloração profissional — diretamente à porta dos clientes, com a praticidade do delivery e a excelência de **profissionais renomados de Maceió, Alagoas**.

> *"Não somos mais um salão. Somos o padrão de referência em beleza delivery no Nordeste."*

### 🏆 Nossa Proposta

Alagoas tem talento, tem mercado e tem demanda. Este sistema nasce com a missão de **posicionar profissionais alagoanos de excelência** no centro do ecossistema digital de beleza, unindo tecnologia de ponta com o calor e a expertise da nossa gente.

- **Para os clientes:** Agendamento fácil, atendimento em domicílio, produtos premium e acompanhamento em tempo real.
- **Para os profissionais:** Gestão financeira transparente, controle de estoque automatizado e uma plataforma para crescer sem depender de salão físico.
- **Para o mercado alagoano:** Uma solução 100% local, construída para as necessidades de quem vive em Maceió.

## ⚡ Módulos do Sistema

### 📦 Gestão de Estoque
Controle total dos insumos do salão — gramaturas de Mega Hair, tintas, queratina, fitas adesivas e produtos de revenda home care — com **baixa automática** ao concluir cada atendimento.

### 💰 Módulo Financeiro
Painel gerencial completo com **fluxo de caixa em tempo real**, split automático de repasses para profissionais, métricas de faturamento diário/semanal/mensal e relatórios exportáveis.

### 👥 CRM Inteligente
Sistema de **campanhas de resgate** que identifica clientes inativos, segmenta por histórico de serviço e valor gasto, e dispara mensagens personalizadas via WhatsApp ou e-mail.

## 🚀 Setup Local

### Pré-requisitos
- Node.js 20+
- Docker Desktop (para PostgreSQL local opcional)
- npm ou pnpm

### 1. Clonar o repositório
```bash
git clone https://github.com/eupordias/salao-delivery-maceio.git
cd salao-delivery-maceio
```

### 2. Configurar variáveis de ambiente
```bash
cp backend/.env.example backend/.env
cp frontend/.env.local.example frontend/.env.local
```

### 3. Instalar dependências
```bash
# Backend
cd backend && npm install

# Frontend
cd ../frontend && npm install
```

### 4. Banco de dados (Supabase já configurado)
```bash
cd backend
npx prisma generate
npx prisma db push
npx tsx src/prisma/seed.ts
```

### 5. Rodar em desenvolvimento
```bash
# Terminal 1 - Backend (porta 3001)
cd backend && npm run dev

# Terminal 2 - Frontend (porta 3000)
cd frontend && npm run dev
```

## 📡 API Endpoints

### Estoque (`/api/admin/inventory`)
| Método | Rota | Descrição |
|--------|------|-----------|
| GET | `/` | Lista produtos com status OK/Baixo/Crítico |
| POST | `/` | Cadastra novo produto |
| PUT | `/:id` | Atualiza produto |
| DELETE | `/:id` | Remove produto |
| GET | `/movements` | Histórico de movimentações |
| POST | `/:id/adjust` | Ajuste manual de estoque |
| POST | `/appointments/:id/complete` | **Baixa automática** pós-atendimento |

### Financeiro (`/api/admin/financial`)
| Método | Rota | Descrição |
|--------|------|-----------|
| GET | `/cash-flow` | Fluxo de caixa com série diária |
| GET | `/reports` | Relatório consolidado por período |
| GET | `/metrics` | KPIs: hoje, mês, ticket médio |
| POST | `/transactions` | Lançamento manual |

### CRM (`/api/admin/crm`)
| Método | Rota | Descrição |
|--------|------|-----------|
| GET | `/inactive-clients` | Clientes segmentados por inatividade |
| GET | `/vip-clients` | Clientes VIP por gasto acumulado |
| GET | `/inactive-clients/export-csv` | Exportação CSV |
| GET | `/campaigns` | Lista campanhas |
| POST | `/campaigns` | Cria campanha |
| POST | `/campaigns/:id/trigger` | Dispara via WhatsApp/E-mail |
